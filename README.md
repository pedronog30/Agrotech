# AgroConsulta (versão React — Fase 5)

Este projeto foi migrado do site estático (HTML/CSS/JS puro) para
React + Vite, mantendo o mesmo visual e as mesmas funcionalidades
de cada página.

## Como rodar

```
npm install
npm run dev
```

Abra o endereço que aparecer no terminal (geralmente http://localhost:).



## Arquivos antigos

A versão original em HTML/CSS/JS puro (Fase 4) foi guardada na
pasta `legado-html/`, incluindo os arquivos `.js` que agora não são
mais usados (a lógica deles foi reescrita dentro dos componentes
React).
